## ⚙️ 配置选项详解

### 📋 基本配置
- **日志路径**: 指定要分析的日志文件路径
- **输出目录**: 分析报告的保存位置
- **报告格式**: HTML/JSON/CSV/TXT格式选择
- **分析选项**: 启用/禁用各种优化功能

### 🤖 AI分析配置
- **AI模型类型**:
  - 云端 DeepSeek - 需要API密钥
  - 本地 LM Studio - 本地AI模型
  - 本地 Ollama - 开源大模型
- **模型名称**: 选择具体的AI模型
- **并发处理数**: 同时处理的日志条目数量（1-20）
- **API密钥**: 云端服务的认证密钥

### ⚡ 性能优化配置
- **处理块大小**: 内存读取块大小（1024-65536字节）
- **最大内存使用**: 内存使用上限（50%-90%）
- **批处理大小**: 批量处理的大小（10-1000）
- **处理超时**: 单个操作的超时时间（10-300秒）

### 🔒 安全配置
- **验证级别**: 输入验证的严格程度
  - 宽松 - 基本验证
  - 适中 - 标准验证（推荐）
  - 严格 - 严格验证
  - 偏执 - 最严格验证
- **威胁检测**: 启用/禁用特定威胁类型检测
  - SQL注入检测
  - XSS攻击检测
  - 路径遍历检测
  - 命令注入检测

### 💾 缓存配置
- **缓存大小**: 内存缓存的最大条目数
- **缓存策略**:
  - LRU - 最近最少使用（推荐）
  - LFU - 最少使用频率
  - FIFO - 先进先出
- **缓存TTL**: 缓存项的生存时间（60-3600秒）

## 🚨 威胁检测结果

### 实时威胁监控
- **时间戳**: 威胁检测的具体时间
- **威胁类型**: 检测到的威胁类别
- **风险评分**: 威胁的严重程度（0-10分）
- **预览**: 威胁日志内容的预览

### 风险等级颜色编码
- 🔴 **红色** (8.0-10.0): 高危威胁
- 🟠 **橙色** (5.0-7.9): 中危威胁
- 🔵 **蓝色** (0-4.9): 低危威胁

## 📊 实时性能监控

### 关键指标
- **💾 内存**: 当前内存使用率
- **⚡ 速度**: 日志处理速度（条/秒）
- **🎯 缓存**: 缓存命中率和缓存项数

### 性能优化建议
1. **内存优化**: 大文件处理时启用内存优化
2. **并发设置**: 根据系统性能调整并发数
3. **缓存策略**: 重复分析时启用缓存
4. **批处理大小**: 平衡内存使用和处理速度

## 🔧 故障排除

### 常见问题及解决方案

#### 1. GUI启动失败
```
问题: ImportError: No module named 'PyQt6'
解决: pip install PyQt6
```

#### 2. AI连接失败
```
问题: AI服务连接超时
解决:
- 检查网络连接
- 验证API密钥
- 确认AI服务正在运行（本地模型）
```

#### 3. 内存不足
```
问题: 大文件处理时内存不足
解决:
- 降低最大内存使用率到70%
- 增加批处理大小
- 启用内存优化选项
```

#### 4. 分析速度慢
```
问题: 分析处理速度较慢
解决:
- 启用缓存系统
- 增加AI并发处理数
- 使用内存优化模式
```

#### 5. 威胁检测过多误报
```
问题: 正常日志被误判为威胁
解决:
- 降低验证级别到"适中"
- 关闭不需要的威胁检测类型
- 调整威胁检测规则
```
